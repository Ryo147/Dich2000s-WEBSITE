How to Use
  1. 01

    Download the tool

    Click the "Download" button (Windows) above to get the latest PatchVietHoaInstaller_win-x64.exe file from GitHub Releases.

  2. 02

    Open the tool

    Run the .exe file you just downloaded. If Windows SmartScreen shows a warning, click "More info" → "Run anyway". The tool will show a list of games that already have a Vietnamese patch.

  3. 03

    Choose a game & install folder

    Pick the game you want to patch, then browse to the game's install folder on your PC (usually inside Program Files or your Steam folder).

  4. 04

    Install & play

    Click install, wait for the tool to finish, and enjoy!

  1. 01

    Download & extract

    Click the "Download" button (Linux) above to get PatchVietHoaInstaller_linux-x64.zip. Extract it with unzip or any file manager that supports .zip:

    unzip PatchVietHoaInstaller_linux-x64.zip
  2. 02

    Make it executable

    Open a terminal in the extracted folder and give the file execute permission:

    chmod +x PatchVietHoaInstaller
./PatchVietHoaInstaller
  3. 03

    Choose a game & install folder

    Pick the game you want to patch, then browse to its install folder (for example, a Steam Proton folder: ~/.steam/steam/steamapps/common/<game name>).

  4. 04

    Install & play

    Click install, wait for the tool to finish, and enjoy!

Frequently Asked Questions
Windows SmartScreen / my browser warns that the file is dangerous. Is that a problem?

This is the default warning for .exe files without a commercial digital signature (which is very expensive for a small translation group). You can check the VirusTotal scan results above or review the source code yourself before running it.

VirusTotal reports "Trojan[Downloader]/MSIL.BaseLoader" (Antiy-AVL). Is it dangerous?

No. This is a heuristic warning from the Antiy-AVL engine alone - out of 69 engines on VirusTotal, only this one flagged it, and the other major antivirus engines all confirm it is clean. See the "Security Results" section above for details.

Why is the Linux build a .zip instead of a .tar.gz / AppImage?

For now the team packages it as a .zip to keep things simple. AppImage/.tar.gz may be supported in later versions if enough Linux users ask for it.

Does the tool support macOS?

There is no macOS version yet. If you use a Mac, you can join the team's Discord to follow progress or contribute code.

Where do I report an installation error?

You can open an issue on GitHub with a screenshot of the error, or message us directly in the team's Discord channel for faster support.
