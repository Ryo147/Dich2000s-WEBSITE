Công cụ này hoàn toàn miễn phí. Nếu bạn thấy nơi nào yêu cầu trả phí để lấy được phần mềm này, đó chắc chắn là lừa đảo - vui lòng chỉ tải từ trang GitHub chính thức của nhóm bên dưới.

Cách sử dụng
  1. 01

    Tải công cụ

    Bấm nút "Tải về" (Windows) phía trên để lấy file PatchVietHoaInstaller.exe mới nhất từ GitHub Releases.

  2. 02

    Mở công cụ

    Chạy file .exe vừa tải về. Nếu Windows SmartScreen cảnh báo, bấm "More info" → "Run anyway". Công cụ sẽ hiển thị danh sách các game đã có bản Việt hóa.

  3. 03

    Chọn game & thư mục cài đặt

    Chọn tựa game muốn cài đặt Việt hóa, chọn đến thư mục cài đặt game trên máy bạn (thường trong Program Files hoặc thư mục Steam).

  4. 04

    Cài đặt & chơi

    Bấm cài đặt, đợi phần mềm xử lý xong và tận hưởng thôi!

  1. 01

    Tải & giải nén

    Bấm nút "Tải về" (Linux) phía trên để lấy file PatchVietHoaInstaller-linux.zip. Giải nén bằng unzip hoặc trình quản lý file hỗ trợ định dạng .zip:

    unzip PatchVietHoaInstaller-linux.zip
  2. 02

    Cấp quyền chạy

    Mở terminal tại thư mục vừa giải nén và cấp quyền thực thi cho file:

    chmod +x PatchVietHoaInstaller
./PatchVietHoaInstaller
  3. 03

    Chọn game & thư mục cài đặt

    Chọn tựa game muốn Việt hóa, chọn đến thư mục cài đặt game (ví dụ thư mục Steam Proton: ~/.steam/steam/steamapps/common/<tên game>).

  4. 04

    Cài đặt & chơi

    Bấm cài đặt, đợi phần mềm xử lý xong và tận hưởng thôi!

Đây là một trường hợp false positive tương đối phổ biến, đặc biệt đối với các ứng dụng .NET nhỏ mà chưa có chữ ký số thương mại.

Nếu bạn vẫn còn lo lắng
  • Đối chiếu mã băm SHA-256 của file bạn tải với mã băm chính thức trên trang GitHub Releases (xem mục "Kiểm tra toàn vẹn file" bên dưới).
  • Xem chi tiết kết quả 69 engine trực tiếp trên VirusTotal qua nút "Xem chi tiết" ở trên - chỉ 1 engine gắn cờ.
  • Xem mã nguồn công cụ công khai trên GitHub (mục "Mã nguồn" cuối trang) để tự kiểm tra hoặc tự build.
  • Nếu chưa yên tâm, bạn hoàn toàn có thể chờ nhóm cập nhật chữ ký số hoặc phản hồi thêm qua Discord trước khi cài đặt.

Kiểm tra toàn vẹn file

Sau khi tải về, bạn có thể tự đối chiếu mã băm SHA-256 để chắc chắn file không bị chỉnh sửa trong quá trình tải. Xem mã băm chính thức trên trang GitHub Releases 4.2.0.1 .

Windows
certutil -hashfile PatchVietHoaInstaller.exe SHA256
Linux
sha256sum PatchVietHoaInstaller-linux.zip
Câu hỏi thường gặp
Windows SmartScreen / trình duyệt cảnh báo file nguy hiểm, có sao không?

Đây là cảnh báo mặc định cho các file .exe chưa có chữ ký số thương mại (rất tốn phí với nhóm dịch nhỏ lẻ). Bạn có thể đối chiếu kết quả quét VirusTotal ở trên hoặc tự kiểm tra mã nguồn trước khi chạy.

VirusTotal báo "Trojan[Downloader]/MSIL.BaseLoader" (Antiy-AVL), có nguy hiểm không?

Không. Đây là cảnh báo heuristic của riêng engine Antiy-AVL - trong tổng 69 engine trên VirusTotal, chỉ mình engine này gắn cờ, các engine antivirus lớn khác đều xác nhận sạch. Xem chi tiết ở mục "Kết quả bảo mật" phía trên.

Vì sao bản Linux là .zip chứ không phải .tar.gz / AppImage?

Hiện tại nhóm đóng gói tạm bằng .zip cho đơn giản. Định dạng AppImage/.tar.gz có thể sẽ được hỗ trợ ở các bản sau nếu có nhiều người dùng Linux phản hồi.

Công cụ có hỗ trợ macOS không?

Hiện chưa có bản macOS. Nếu bạn dùng Mac, bạn có thể tham gia Discord của nhóm để theo dõi tiến độ hoặc đóng góp mã nguồn.

Gặp lỗi khi cài đặt thì báo ở đâu?

Bạn có thể mở issue trên GitHub kèm ảnh chụp lỗi, hoặc nhắn trực tiếp trong kênh Discord của nhóm để được hỗ trợ nhanh hơn.
