Phần mềm cài đặt riêng của nhóm Dịch 2000s. Chỉ áp dụng cho những tựa game mà nhóm đã dịch xong. Phần mềm giúp việc cài đặt bản Việt hóa gọn nhẹ, không cần thao tác thủ công phức tạp.

Công cụ này hoàn toàn miễn phí. Nếu bạn thấy nơi nào yêu cầu trả phí để lấy được phần mềm này, đó chắc chắn là lừa đảo — vui lòng chỉ tải từ trang GitHub chính thức của nhóm bên dưới.

Cách sử dụng
  1. 01

    Tải công cụ

    Bấm nút "Tải về" (Windows) phía trên để lấy file PatchVietHoaInstaller.exe mới nhất từ GitHub Releases.

  2. 02

    Mở công cụ

    Chạy file .exe vừa tải về. Nếu Windows SmartScreen cảnh báo, bấm "More info" → "Run anyway". Công cụ sẽ hiển thị danh sách các game đã có bản Việt hóa.

  3. 03

    Chọn game & thư mục cài đặt

    Chọn tựa game muốn cài đặt Việt hóa, chọn đến thư mục cài đặt game trên máy bạn (thường trong Program Files hoặc thư mục Steam).

  4. 04

    Cài đặt & chơi

    Bấm cài đặt, đợi phần mềm xử lý xong và tận hưởng thôi!

  1. 01

    Tải & giải nén

    Bấm nút "Tải về" (Linux) phía trên để lấy file PatchVietHoaInstaller-linux.zip. Giải nén bằng unzip hoặc trình quản lý file hỗ trợ định dạng .zip:

    unzip PatchVietHoaInstaller-linux.zip
  2. 02

    Cấp quyền chạy

    Mở terminal tại thư mục vừa giải nén và cấp quyền thực thi cho file:

    chmod +x PatchVietHoaInstaller
./PatchVietHoaInstaller
  3. 03

    Chọn game & thư mục cài đặt

    Chọn tựa game muốn Việt hóa, chọn đến thư mục cài đặt game (ví dụ thư mục Steam Proton: ~/.steam/steam/steamapps/common/<tên game>).

  4. 04

    Cài đặt & chơi

    Bấm cài đặt, đợi phần mềm xử lý xong và tận hưởng thôi!
